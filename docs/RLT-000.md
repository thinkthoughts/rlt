# RLT-000 — Approved architecture (summary)

The full review lives in the RLT-000 doc (revision 2, 2026-11-07). This file records what was approved for RLT-001.

## Approved (§9 items 1–4)

1. Module structure (§7), as implemented in this repository.
2. Rust for kernel, syntax and CLI; Lean as an independent replay.
3. Sequent kernel with the `hyp` rule: every result keeps its assumption context Γ; composition preserves Γ; a result is unconditional only when Γ = ∅.
4. Status vocabulary: RML's {unestablished, supported, rejected, inapplicable} plus `imagined`; lifts {proposed, specified, verified}.

## Implementation requirements attached to the approval

1. Keep the four layers: written expression, convention, checked relationship, physical correspondence.
2. Use Rust and the proposed module structure.
3. Keep assumptions with every result; report a result as unconditional only when its context is empty.
4. Keep `imagined` apart from mathematical validity and from physical evidence status.
5. Treat convention files and source documents as inputs to interpretation; report the exact statement the kernel checked.
6. Keep every documented meaning of math0, math5 and math29; arithmetic relationships are attached results.
7. Keep the PiπΠ source conventions without inventing definitions for unresolved glyph meanings.

## Four layers

| Layer | Holds | Decides | Where |
|---|---|---|---|
| 1 · Written expression | exact text + token sequence | written identity (≡w) | `syntax/src/written.rs` |
| 2 · Convention | named, source-traced reading of notation | which term a written expression denotes | `conventions/`, `syntax/src/elab.rs` |
| 3 · Checked relationship | kernel sequent Γ ⊢ s = t, axioms used | mathematical equality | `kernel/` (trusted) |
| 4 · Physical correspondence | behavior, representation and referent records with evidence | physical status | `readingpoints/*.yaml`, `correspondence/` |

## Still open (§9 items 5–7)

6. The attachment's `(1+1)×3×15 = 90` and `0.96 ≠ 90`: to become regression tests once their convention is named.
7. Missing sources (ChatGPT RLT discussion, SDG5 specification, CO₂ specifications, formalize.now): registered as `missing` in `sources/registry.yaml`.
