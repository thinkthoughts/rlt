## 2. Formal statement and proof

`matchable.not.8` (`tests/rlt005/accept/MN8_eight_is_not_matchable.rlt`) states the theorem below. It holds under Robinson's Q with NAT-DEF and Γ = ∅.

```
(MD8 ∧ MP4) ∧ ¬∃a b c d. (ranges ∧ distinct) ∧ (cop(1,a) ∧ cop(2,b) ∧ cop(4,c) ∧ cop(8,d))
cop(m,x) := ∀k. ((0 < k ∧ k ∣ m) ∧ k ∣ x) → k = 1
```

The terms are defined in `docs/RLT-005-CORRESPONDENCE.md` §2. All 19 files below are generated by `scripts/gen-rlt005.py`, which is untrusted, and all are accepted by the kernel: 1,271 steps in total.

**How the impossibility is proved.** The central argument is checked rule by rule. There is no generator assertion and no reported search.

1. MC cites MO2, MO4 and MO8 to place b, c and d in {1, 3}.
2. MPH, which is pure logic, gives b = c ∨ b = d ∨ c = d.
3. `or-cases` against the distinctness hypotheses gives ⊥.

Each MO lemma enumerates the partner range (MP4). It refutes x = 2 and x = 4 using the common divisor 2: it cites 2 ∣ 2, 2 ∣ 4 and 2 ∣ 8 from the earlier library, and concludes 2 = 1 → ⊥ by Q1 and Q2.

## 3. Source-correspondence findings

The basis is `docs/RLT-005-CORRESPONDENCE.md`, pinned by hash in the record. Its main points:

- **Matches.** Over ℕ, the four RLT conditions are exactly a coprime matching between D(8) and {1, …, τ(8)} in the paper's sense. Lean proves this as `explicit_iff` for any four distinct positive divisors, and `matchable'_eight_iff` for D(8); the direction of the matching is immaterial (`matchable_iff`). The RLT proof specialises the paper's argument on line 96 to n = 8.
- **Differs.**
  1. The bridge from "matchable" to the explicit formula is a Lean theorem over ℕ, not an RLT theorem: RLT has no sets, bijections or cardinality. τ(8) = 4, and the fact that the clause numerals are the divisor list, are checked in Lean and by reading the goal.
  2. Only the first claim on line 94 is covered. "Nor is any subsequent multiple of 4" needs induction.
- **The Q obstruction, `0 < d` and `0 < k`.** Q cannot prove 0 × x = 0. Here is a model of Q with 0 ∣ V for a nonzero V:
  - domain ℕ ∪ {A};
  - S(A) = A;
  - A + n = n + A = A + A = A;
  - x·A = A for x ≠ 0, A·0 = 0, A·n = A for n > 0, and 0·A = V.

  The axioms hold case by case:
  - Q1, Q2 and Q3 hold because S(A) = A is not a successor of a standard number, and A = S(A).
  - add_zero: A + 0 = A.
  - add_succ: x + S(A) = A = S(x + A), and A + S(n) = A = S(A + n).
  - mul_zero: A·0 = 0.
  - mul_succ, case x·S(A): x·A = x·A + x for x ≠ 0, since A + x = A; and 0·S(A) = 0·A = V = V + 0.
  - mul_succ, case A·S(n): A = A·n + A in both the n = 0 and n > 0 cases.

  So `0 < d` is necessary. With V = 8, MD8 without it is false. `0 < k` makes the theorem stronger, not weaker. In this model, cop(1, 1) without `0 < k` fails (V = 1), so non-vacuity needs it.
- **Status `partial`**, attributed to the RLT-005 review on 2026-11-11. Both auditors agreed that `matches` would overstate it.

**Implementation.** The auditor confirmed that the hard constraints hold: the kernel and spec are unchanged, reports and identities are preserved, and no new checker entry point was added.

1. *should-fix.* The plain-gzip fallback ignored the member name. **Fixed:** the member must be named in the gzip header, and the shared member-path rule applies in both Python and Rust.

6. *Fixture names.* **Fixed:** XN05 renamed. A forged basis pin giving exit 0 with "assessment stale" is the RLT-004b design (XA02), recorded here unchanged.
7. *Writing the cache through a symlink.* **Fixed:** a symlink is refused, and the cache is written to a temporary file and then renamed into place.
