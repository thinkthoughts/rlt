## 4. Phase 3 · F-009 and F-018

**F-009** is held on `research/rlt-cstar-005-dic-uptake` (`cbeacaa2`, unchanged) and on `hold/rlt-cstar-008-f009-on-integration` (`63fa80de`, `cfc038e9`, cherry-picked with `-x` onto the ROMS-Tools integration branch). There, after resolving a textual test-file conflict, 162 analysis tests pass, so the change composes with the revised units contract. It is never part of an integration branch.

**F-018** (`research/rlt-cstar-008/f018_initial_difference.{py,out}`): the box model is extended with initial differences Δ₀ (DIC) and A₀ (alkalinity), dU/dt = k(c(A₀ + a·t) + r·t − Δ₀ − U), so U = U₀ + (c·A₀ − Δ₀)(1 − e^{−kt}). Three-day values (mmol), with the F-009 change:

| Case | U₀ (equal start) | flux method | DIC method | DIC − flux | at first record |
|---|---|---|---|---|---|
| OAE, equal start | 999,655 | 999,655 | 999,655 | 0 | 0 |
| OAE, offset Δ₀ = 5×10⁵ with A₀ = 0 | 999,655 | 611,220 | 1,111,220 | 500,000 | 500,000 |
| OAE, restart Δ₀ = c·A₀ = 5×10⁵ | 999,655 | 999,655 | 1,499,655 | 500,000 | 500,000 |
| DOR, offset Δ₀ = 5×10⁵ with A₀ = 0 | 1,249,569 | 861,134 | 1,361,134 | 500,000 | 500,000 |
| DOR, restart Δ₀ = c·A₀ | 1,249,569 | 1,249,569 | 1,749,569 | 500,000 | 500,000 |

Established: the methods differ by exactly Δ₀, already at the first output record. An unsupported offset changes even the flux method. A restart near equilibrium leaves the flux method exact and makes the inventory method cumulative. Without the F-009 change, the DOR rows mix Δ₀ with the removed DIC (−2,092,000). The questions are in `RLT-CSTAR-008-SCIENTIFIC-QUESTIONS.md`.

## 6. `REPLAY.sh`, run end to end

- `git -C repo worktree add wt/...` resolves the path inside the repository; paths are now absolute.
- The tamper helper ran the kernel outside the rlt checkout, where `spec/robinson-q.rlt` does not resolve, so every certificate came back MALFORMED instead of being tested. The helper now runs in the checkout, and checks each untampered certificate as a control.

- the coarse harness output byte-identical, with 0 mismatches;
- 144 analysis tests pass, and `Mmol` is again accepted by the unrevised 003;
- tonnes exact;
- `CSF` output identical;
- the kernel binary hash identical (`da49aee1…`);
- 17 ACCEPT and 1 MALFORMED, and for every certificate the control is ACCEPT and the tampered copy REJECT;
- Lean: 26 axiom lines, no error or `sorry`.
