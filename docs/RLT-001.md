# RLT-001 — Initial implementation and verification report

> **Updated after the independent audit.** This report describes commit `2428e3a`/`76de973`. The audit found defects around the kernel (axiom selection, relationship binding, record fidelity, `verify.sh` exit status, resource limits); they are fixed in `687f5e8`. See `docs/RLT-001-AUDIT.md` for the findings, fixes and current results (43 tests). Where this report and the audit report differ, the audit report is current: axioms now come from registered, hash-locked sets (`spec/axioms.yaml`); numerals are capped at 1000; meanings are checked as whole verbatim units with completeness.

**Objective.** RLT independently checks a valid derivation, rejects an invalid derivation, and preserves the specifications and assumptions associated with both.

**Result.** Met. All 10 proof files give their intended verdicts. The 30 tests (24 unit, 6 integration) and the record validation pass. The independent Lean replay agrees on every statement. Implementation commit `2428e3a`; full run log in `verification/RLT-001-results.txt`; reproduce with `scripts/verify.sh`.

## 5. Kernel review findings fixed before commit

- A duplicate axiom name would have silently replaced the earlier axiom. The checker now rejects a duplicate registration (`check::tests::unregistered_rules_labels_axioms_and_assumptions_are_rejected`).
- A very large numeral in a proof file could exhaust memory, since kernel numerals are unary. Proof syntax and NAT-DEC now cap numerals at 10000 and report MALFORMED.

## 6. Differences from RLT-000 to note

- **PI-6 source.** The "conceivable ≠ measured" statement comes from an antiviolence.ai feed post (`ANTIVIOLENCE-FEED-CONCEIVABLE`), which cites translatepi.ai. RLT-000 §1.4 attributed it to translatepi.ai's own `feed.json`.
- **Relationship status.** Verdicts are computed live by `rlt rp` and `rlt check`. Records store none, so a stale `checked(hash)` status can never appear. Theorem hashes are deferred until lifts need to reference them.
- **File names.** The correspondence schema is `correspondence/schema.md`. Lifts live inside the reading-point files, with `lifts/README.md` describing the format. The syntax crate's files are `written.rs`, `elab.rs`, `proof.rs`, `sexpr.rs` and `records.rs`.
- **Physical status of the emoji representation.** `math0.emoji` (🫁 represents human lungs) is marked `inapplicable`, since it is a relation of written signs. The lungs referent is `unestablished`, and the emoji's own breathing is `imagined`.
